About

The Overlord is a Discord bot with a per-server economy, optional games, a shared “realm” layer (weather, events, board, Gazette), a global World Campaign that every server can join, and a full moderation toolkit for server owners.

What it is (and isn’t)

  • Virtual coins and items have no real-world value.
  • Progress is per server, except for features that are shared on purpose: raids, the global leaderboard and the World Campaign.
  • The moderation tools are run by each server’s own staff; the bot only does what they set up.
  • Not affiliated with Discord Inc.
  • Provided as-is; see Terms and Privacy.
