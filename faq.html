Help

FAQ

Short answers to the questions that come up most. For setup steps see Setup; for bugs join support.

Basics

  • How do I use the bot?
    Commands start with !! by default. Try !!help and !!tutorial in a channel the bot can see.
  • Can the prefix be changed?
    Yes. Someone with Manage Server can run !!prefix <new prefix>, and !!prefix reset puts it back. !!help always works on !! and shows the current prefix.
  • Do slash commands work?
    Some exist, but they’re experimental. Prefix commands are the reliable way, and moderation is prefix-only.
  • Is this a full Discord RPG I have to play?
    No. There’s an economy and optional games. You can mostly ignore them and still use moderation, the realm board, weather, and events if those are set up.

Moderation

  • Can the bot moderate my server?
    Yes: warnings, mutes, kicks, bans (including timed bans), purge, slowmode, lock, automod, anti-raid, welcome messages and a mod log. Run !!modhelp for the list, or see Setup.
  • Who can use the moderation commands?
    Anyone with the matching Discord permission (for example Moderate Members to warn or mute). Admins can also add a moderator role with !!modrole add @role. Kick, ban, nickname and role changes always need the real Discord permission.
  • The bot says it can’t moderate someone.
    Its role has to be above the person’s highest role (and it can never act on the server owner). Drag the bot’s role up in Server Settings → Roles. If it names a missing permission, give it to the bot’s role.
  • Does automod punish people?
    By default it deletes the message and posts a short notice. !!automod punish warn also adds a warning, which can trigger automatic actions you set with !!modconfig warnaction. Staff are never checked, and you can ignore channels or roles.
  • Where is moderation data stored?
    Per server, in the bot’s database. It is removed with the rest of that server’s data. See the Privacy Policy.

Coins, Campaign & data

  • Are coins real money?
    No. They’re virtual, per server, and worth nothing outside the bot.
  • Do my coins transfer between servers?
    No. Each server has its own economy and progress. The exceptions are features that are shared on purpose: cross-server raids, the global leaderboard and the World Campaign.
  • What is the World Campaign?
    One shared map where every server is a house. Members spend their own coins on troops, take cities and fight for provinces. Seasons reset the map every month. Start with !!guide, and see the live map on the Campaign page.
  • What does voting give me?
    Vote on top.gg, then run !!vote for coins and a short earn boost. You can claim once every 12 hours, and weekends pay more.
  • Can I delete my data?
    Server admins can use !!deletedata in Discord. Anyone can also contact us via the Privacy Policy.
  • Why am I on the website leaderboards?
    Only if that server has website listing on and you haven’t hidden yourself with !!webhide.

Admins

  • What should I set up first?
    !!settings events #channel for announcements, optional !!settings board #channel for the living realm board, and !!modlog #channel plus !!modrole add @role if you want to moderate with the bot. Full list on Setup.
  • Can I turn off rob or gambling?
    Yes — !!settings rob off and !!settings gambling off.
  • Can I remove the server from the website?
    !!settings website off. Takes effect on the next data update (about 15 minutes).
  • What permissions does the bot need?
    View Channel, Send Messages (including in threads), Embed Links, Attach Files, Read Message History, Add Reactions. For moderation also Manage Messages, Manage Channels, Manage Roles, Manage Nicknames, Kick Members, Ban Members, Moderate Members and View Audit Log. The invite link on this site asks for all of them, and none of them is Administrator.

Problems

  • The bot ignores commands.
    Check it can see the channel, the channel isn’t ignored in !!settings, and you’re using the right prefix. Type !!help to see your server’s prefix.
  • No events / Gazette.
    Set an events channel. The bot won’t post those until you do.
  • Something’s broken.
    !!report or !!feedback in Discord, or support server.
