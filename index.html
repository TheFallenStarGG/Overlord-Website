What you actually get

  • 🗺️

    World Campaign

    One shared map. Your server is a house. Take cities, siege neighbors, collect taxes, fight the AI Shadow Court. Seasons reset the board. Live map →

  • 📰

    The Gazette

    A daily newspaper image for the realm — richest players, headlines, weather, campaign notes. Today’s papers →

  • 🪙

    Economy

    Daily, work, shop, fish, mine, rob, bank, heists. Optional scarce mode. Coins are per-server and worthless IRL.

  • 📈

    Stocks & chaos

    Companies rise, crash, get bought out. Weather, decrees, bounties, rebellion meter. Market →

  • ⚔️

    Combat & raids

    Duels, bosses, gear, ranked play, cross-server raids. Turn raids off per server if you don’t want them.

  • 🎮

    Games

    Wordle, cards, board games, a few gamble commands (admins can disable betting). Prefix is still !! everywhere.

First five minutes

Players

  1. !!tutorial — short walkthrough
  2. !!daily · !!work · !!balance
  3. !!campaign map — see the world war
  4. !!vote after voting on top.gg (coins every 12h)

Admins

  1. Invite (Manage Server). Open Setup.
  2. !!events-channel #channel — Gazette & world posts
  3. !!tutorial admin · !!settings
  4. Optional: !!raid-config optout if you don’t want raids
