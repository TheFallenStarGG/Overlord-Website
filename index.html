What the bot is for

  • Make money, spend it, risk it

    Work, fish, mine, daily rewards, a shop, bank, stocks, and games when you want something louder. Progress is per server so each community has its own economy.

  • World Campaign

    Every server is one house on a shared map. Recruit, move, siege cities, and watch the board change over the season. Open Campaign for the live overview.

  • The Gazette

    A daily newspaper-style image for the realm—not a wall of embeds. Admins can point it at an events channel; anyone can peek on the Gazette page.

  • Moderation that stays out of slash limits

    Warn, mute, kick, ban, purge, slowmode, lock, roles, automod, anti-raid, and welcome messages— all as simple !! commands. Start with !!modhelp.

  • Cross-server spice

    Raids, rivalries, and world events when your community wants something bigger than one channel. Optional, and admins can tune or opt out.

  • Built for Discord, not a second app

    Prefix commands, clear help pages, and a website for maps, stocks, and status when you want the wide view.

First five minutes

  1. Add the bot with the button above (or !!invite from any server that already has it).
  2. In your server, run !!help — that’s the table of contents for everything.
  3. Try !!daily, !!work, or !!balance to touch the economy.
  4. Admins: !!settings, !!events-channel, and !!modhelp when you’re ready.
  5. Optional: vote on top.gg, then !!vote for a small reward.
