Moderation for server owners

A complete toolkit that runs on prefix commands only. Target people by mention, by user ID, or by replying to their message. Every action gets a case number and can be logged to a channel you pick. Run !!modhelp in your server for the full list.

  • ⚠️

    Warnings & cases

    Warnings stack and can trigger automatic actions. Private notes, full history, and editable reasons.

    !!warn!!warnings!!note !!history!!case
  • 🔨

    Punishments

    Timeouts, kicks, bans (even for users who left), timed bans that lift themselves, and softbans that wipe recent messages.

    !!mute!!kick!!ban !!tempban!!softban!!unban
  • 🧹

    Channel control

    Bulk-delete messages with user or bot filters, set slowmode, and lock or unlock a channel in one command.

    !!purge!!slowmode !!lock!!unlock
  • 🤖

    Automod

    Catches invites, links, spam, excessive caps, mass mentions and blocked words. Allow specific domains, ignore channels or roles, and choose delete-only or delete + warn.

    !!automod
  • 🚨

    Anti-raid & welcome

    Join-spike protection, a minimum account age filter, optional channel soft-lock and alerts. Plus a welcome message with {user}, {server} and {membercount}.

    !!antiraid!!welcome
  • ⚙️

    Setup & members

    Pick a mod log channel, set moderator roles, and choose automatic actions (like 3 warnings → 1 hour mute). Nicknames, roles and user info included.

    !!modlog!!modrole!!modconfig !!nick!!role!!userinfo

The bot needs the matching Discord permissions (Moderate Members, Kick/Ban Members, Manage Messages, Manage Channels, Manage Roles) to act. If one is missing, it tells you which. Anti-raid also needs the Server Members intent. Full details on the Setup and Commands pages.
