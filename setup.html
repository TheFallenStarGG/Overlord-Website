Admins

Setup

You need Manage Server for most of this. The bot needs permission to see the channel, send messages, and embed links. Commands start with !! unless you change the prefix (see below).

Invite permissions

The invite is not Administrator. It asks for:

View Channel Send Messages Send Messages in Threads Embed Links Attach Files Read Message History Add Reactions Use External Emojis Manage Messages Manage Channels Manage Roles Manage Nicknames Kick Members Ban Members Moderate Members View Audit Log

The moderation permissions (Manage Messages, Manage Channels, Manage Roles, Manage Nicknames, Kick, Ban, Moderate Members) are only used when someone runs a moderation command or you turn on automod or anti-raid. If one is missing the bot tells you which. Role order matters: the bot’s role must sit above any member or role it needs to moderate, so drag it up in Server Settings → Roles. Prefix commands need the Message Content intent, and anti-raid and welcome messages need the Server Members intent. Both are already enabled on the bot’s application.

Channels

  1. Events feed — ongoing announcements (bounties, weather, market crashes, etc.):
    !!settings events #channel
  2. Realm board — one message that edits itself (“Today in the Realm”):
    !!settings board #channel
    Anyone can also run !!board for a one-off snapshot.
  3. Level-ups (optional):
    !!settings levels #channel
  4. Campaign map (optional) — a live World Campaign map message:
    !!mapchannel #channel

Events channel = stream of posts. Board = single updating post. You can use both.

Moderation

A full toolkit, prefix commands only (no slash). Run !!modhelp any time for the complete list. Set up these four things first:

  1. Mod log — where every action is recorded with a case number:
    !!modlog #mod-log
  2. Moderator role — lets that role warn, mute, purge, lock and set slowmode without extra Discord permissions (kick, ban, nick and role changes still need the real Discord permission):
    !!modrole add @Moderators
  3. Automatic actions — for example 3 warnings → 1 hour mute:
    !!modconfig warnaction 3 mute 1h
    Turn DMs to the people the bot acts on off or on with !!modconfig dm on|off.
  4. Automod — checks messages for you. Staff are never checked.
    !!automod invites on · !!automod spam on · !!automod punish warn
!!warn @user reason Warn (also !!warnings, !!delwarn, !!clearwarns, !!note)
!!mute @user 2h reason Timeout up to 28 days (!!unmute ends it)
!!kick · !!ban · !!tempban @user 3d · !!softban · !!unban id Removals. Ban works on any user ID, even if they left.
!!purge 20 [@user|bots] Bulk delete (not older than 14 days, pinned messages stay)
!!slowmode 10s · !!lock · !!unlock Channel control
!!history @user · !!case 12 · !!reason 12 new text Records
!!nick · !!role add|remove · !!userinfo Members

Everything works by mention, by pasting a user ID, or by replying to the person’s message. The bot refuses to act on people above it or above you in the role list, and on server owners.

Automod, anti-raid & welcome

!!automod Shows every rule and its current setting
!!automod invites|links|spam|caps|mentions|words on|off Switch rules on or off
!!automod punish delete|warn Delete only, or delete and add a warning
!!automod words add|remove|list <word> Blocked words (your message is deleted so the list stays private)
!!automod domains add <site.com> Links you allow even when link filtering is on
!!automod ignore #channel or @role Exempt a channel or role (run again to undo)
!!automod spam 5 5 · mentions 5 · caps 70 Tune the limits. Spammers are muted for 5 minutes.
!!antiraid on Join-spike protection (see !!antiraid for threshold, window, account age, action, alert channel and soft-lock)
!!welcome #channel Welcome {user} to {server}! Join message. Tokens: {user} {server} {membercount}. !!welcome test and !!welcome off also work.

Automod needs Manage Messages in the channels it watches. Anti-raid needs Kick/Ban/Moderate Members, plus Manage Channels if you use soft-lock.

Prefix

The default prefix is !!. Admins can change it for their own server:

!!prefix Show the current prefix
!!prefix ? Change it (example: ?daily afterwards)
!!prefix reset Back to !!

!!help and !!prefix always work on !!, and !!help shows the current prefix, so nobody gets locked out.

Toggles

!!settings gambling on|off Gambling commands
!!settings rob on|off Robbing
!!settings command <name> on|off Disable a specific command
!!settings ignore #channel Bot stays quiet there (no XP either)
!!settings games add #channel Limit games to certain channels
!!raid-config Cross-server raids (category, opt-out)

Run !!settings with no args to see the current config.

World Campaign

  • Every server becomes a house on one shared map the first time someone runs a campaign command.
  • !!guide explains everything. Players start with !!map and !!recruit <city> <amount>.
  • !!mapchannel #channel keeps a live map message updated (Manage Server).
  • Your server’s name and score are shown publicly on the Campaign page.

Optional extras

  • !!edittitles — custom titles in the shop (and optional role links)
  • !!reactionroles — reaction role panels
  • !!tutorial and !!tutorial admin — point new people at the basics
  • !!deletedata — erase this server’s Bot data (asks you to confirm)
