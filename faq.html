Help

FAQ

Short answers to the questions that come up most. For setup steps see Setup; for bugs join support.

Basics

  • How do I use the bot?
    Commands start with !!. Try !!help and !!tutorial in a channel the bot can see.
  • Do slash commands work?
    Some exist, but they’re experimental. Prefix commands (!!) are the reliable way.
  • Is this a full Discord RPG I have to play?
    No. There’s a light economy and optional games. You can mostly ignore them and still use board, weather, and events if those are set up.

Coins & data

  • Are coins real money?
    No. They’re virtual, per server, and worth nothing outside the bot.
  • Do my coins transfer between servers?
    No. Each server has its own economy and progress.
  • Can I delete my data?
    Use !!deletedata in Discord, or contact us via the Privacy Policy.
  • Why am I on the website leaderboards?
    Only if that server has website listing on and you haven’t hidden yourself with !!webhide.

Admins

  • What should I set up first?
    !!settings events #channel for announcements, optional !!settings board #channel for the living realm board. Full list on Setup.
  • Can I turn off rob or gambling?
    Yes — !!settings rob off and !!settings gambling off.
  • Can I remove the server from the website?
    !!settings website off. Takes effect on the next data update (about 15 minutes).
  • What permissions does the bot need?
    View Channel, Send Messages, Embed Links, Read Message History, Add Reactions. Manage Roles only if you use role-linked shop titles.

Problems

  • The bot ignores commands.
    Check it can see the channel, Message Content Intent is on for the app, and the channel isn’t ignored in !!settings.
  • No events / Gazette.
    Set an events channel. The bot won’t post those until you do.
  • Something’s broken.
    !!report or !!feedback in Discord, or support server.
